## Cómo usar una receta

1. Ábrela y léela completa. Es texto plano, sin nada oculto.
2. Pégala en las instrucciones de un Proyecto de Claude, o adjúntala al empezar un chat.
3. Sigue los pasos de la sección "Cómo usarla".

Las recetas no sustituyen a un profesional. Si el tema es salud, dinero o algo legal, consulta a quien corresponda.
